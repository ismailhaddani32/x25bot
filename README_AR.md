# X25 POOL — مشروع Android جديد

هذا مشروع جديد ونظيف؛ لا يحتوي على ملفات أو وظائف X25 BOT السابقة.

## الموجود حالياً
- شاشة رئيسية فيها زر تشغيل وزر إيقاف فقط، مع رابط Instagram للمطور `@x25madara`.
- عند التشغيل يطلب إذن الظهور فوق التطبيقات الأخرى.
- تظهر طبقة شفافة فوق اللعبة بثلاث علامات يدوية: الكرة البيضاء، الكرة الهدف، والجيب.
- اسحب كل علامة إلى مكانها. الخطوط تربط العلامات كدليل بصري.
- اضغط مطولاً على الشريط العلوي لإغلاق الطبقة، أو استخدم زر إيقاف داخل التطبيق.

## حدود النسخة
هذه نسخة أولية للمساعدة اليدوية: لا تلتقط الشاشة ولا تتعرف تلقائياً على الكرات ولا تحسب التصادم الفيزيائي الحقيقي. الخطوط إرشادية فقط، وليست ضماناً لمسار الكرة. لا تتدخل في ملفات اللعبة أو الشبكة ولا تنفذ الضربات تلقائياً.

## البناء
افتح المجلد في Android Studio، ثم Build > Build APK(s). يتطلب Android SDK 35 وJDK 17.
